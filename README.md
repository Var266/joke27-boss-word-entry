One word for make.fun's "One Word for the Boss" bounty: the single word that describes your boss. The program writes it (8 characters) to `/output/entry.txt`.

> Arsonist

Why this word: the boss starts the fire, then sends you in with the hose and takes the credit for the rescue. It is funny on its own, true of the manufactured-emergency boss everyone has met, fresh where the field will be full of micromanager and tyrant, and it works for a boss in a kitchen, a warehouse or an office alike.

## Run it

```sh
node main.ts
```
